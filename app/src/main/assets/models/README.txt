얼굴 비교(본인 확인)용 임베딩 모델 자리.

기대하는 파일: face_recognition_sface.onnx   (OpenCV Zoo 의 SFace 2021dec, Apache-2.0)
  - 입력  : [1, 3, 112, 112] float32, RGB, 0..255 (정규화 없음), 정렬된 얼굴
  - 출력  : [1, 128] 임베딩 (코사인 유사도로 비교)
다른 모델을 쓰려면 SFaceEmbedder.kt 의 전처리/차원을 맞춰 주세요.

이 파일이 없으면 앱은 얼굴 '비교'만 건너뛰고(프로필 사진 만들기는 동작), 화면에 그 사실을 표시합니다.
